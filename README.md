# 🎮 ТРИ РАЗНЫЕ ИГРЫ НА РАЗНЫХ ЯЗЫКАХ ПРОГРАММИРОВАНИЯ

Здесь находятся три интерактивные игры, написанные на разных языках программирования с использованием разных технологий.

---

## 1️⃣ ТЕТРИС (JavaScript + HTML5 + Canvas)

### 📋 Описание
Классическая игра Тетрис с красивой графикой, анимациями и случайными цветами для каждой фигуры.

### 🚀 Как запустить
1. Откройте файл `tetris.html` в любом веб-браузере (Chrome, Firefox, Safari и т.д.)
2. Нажмите кнопку "Начать" для начала игры

### 🎮 Управление
| Клавиша | Действие |
|---------|----------|
| ⬅️ / ➡️ | Движение фигуры влево/вправо |
| ⬇️ | Ускоренное опускание |
| Пробел | Поворот фигуры |
| P | Пауза/Продолжить |

### ✨ Особенности
- ✅ Плавная анимация с использованием requestAnimationFrame
- ✅ Случайные цвета для каждой новой фигуры
- ✅ Система уровней (скорость увеличивается)
- ✅ Подсчёт очков и завершённых линий
- ✅ Красивый пользовательский интерфейс с градиентом

### 💡 Технический стек
- HTML5 Canvas API
- JavaScript (ES6+)
- CSS3 с градиентами и тенями

## 2️⃣ ЗМЕЙКА (Python + Tkinter)

### 📋 Описание
Классическая игра Змейка в отдельном окне с красивым интерфейсом, системой уровней и анимированным персонажем.

### 🚀 Как запустить
```bash
python snake_game.py
```

или

```bash
python3 snake_game.py
```

### 🎮 Управление
| Клавиша | Действие |
|---------|----------|
| ⬆️ / ⬇️ / ⬅️ / ➡️ | Движение змейки |
| W / A / S / D | Альтернативное управление |
| P | Пауза/Продолжить |
| R | Перезагрузка игры |

### ✨ Особенности
- ✅ Открывается в отдельном окне (Tkinter)
- ✅ Красивое оформление с тёмной темой
- ✅ Система уровней с изменением скорости
- ✅ Анимированные глаза у головы змейки
- ✅ Градиентные цвета для тела змейки
- ✅ Отскок еды в случайные позиции
- ✅ Музыкальные и визуальные сигналы (опционально)

### 💡 Технический стек
- Python 3.7+
- Tkinter (встроена в Python)
- Enum для управления направлениями

### ⚙️ Требования
```bash
# Никаких внешних зависимостей не требуется!
# Tkinter обычно уже установлена вместе с Python
```

## 3️⃣ AR ИГРА С ДЕТЕКЦИЕЙ РУК (Python + OpenCV + MediaPipe)

### 📋 Описание
Инновационная AR-игра, где вы ловите цветные объекты, используя жесты вашей руки. Используется компьютерное зрение для детекции рук в реальном времени.

### 🚀 Как запустить

#### Шаг 1: Установите зависимости
```bash
pip install opencv-python mediapipe numpy
```

#### Шаг 2: Запустите игру
```bash
python ar_hand_game.py
```

или

```bash
python3 ar_hand_game.py
```

**Убедитесь, что веб-камера подключена и работает!**

### 🎮 Управление
| Клавиша | Действие |
|---------|----------|
| Движение руки | Ловля объектов |
| Пробел | Пауза/Продолжить |
| R | Перезагрузка игры |
| Q | Выход из игры |

### ✨ Особенности
- ✅ Детекция рук в реальном времени (MediaPipe)
- ✅ Объекты движутся случайно и отскакивают от стен
- ✅ Разные объекты имеют разные количества очков
- ✅ Система уровней (сложность увеличивается)
- ✅ Красивая визуализация с кругами и индикаторами
- ✅ Поддержка двух рук одновременно
- ✅ Таймер игры и статистика

### 💡 Технический стек
- Python 3.7+
- OpenCV (cv2) для обработки видео
- MediaPipe для детекции рук (от Google)
- NumPy для математических операций

### ⚙️ Требования
```bash
pip install opencv-python mediapipe numpy
```

### 🎯 Советы для лучшего опыта
1. **Освещение**: Убедитесь, что в комнате достаточно света
2. **Фон**: Используйте контрастный фон (не одежда того же цвета, что и стена)
3. **Расстояние**: Держитесь на расстоянии 50-100 см от камеры
4. **Скорость интернета**: Первый запуск может занять время на загрузку моделей

## 🔧 Трубошутинг

### Тетрис не запускается
- Проверьте, что файл `tetris.html` открывается в браузере
- Попробуйте обновить страницу (F5)

### Змейка выдаёт ошибку Tkinter
```bash
# Для Linux:
sudo apt-get install python3-tk

# Для macOS:
brew install python-tk

# Для Windows:
# Переустановите Python с галочкой "TCL/TK"
```

### AR игра не видит камеру
```bash
# Проверьте список камер:
python -c "import cv2; print(cv2.VideoCapture(0).isOpened())"

# Попробуйте другой индекс камеры:
# Измените cap = cv2.VideoCapture(0) на cap = cv2.VideoCapture(1)
```

### Низкая производительность AR игры
- Уменьшите разрешение камеры в коде
- Закройте другие приложения
- Обновите драйвера видеокарты
